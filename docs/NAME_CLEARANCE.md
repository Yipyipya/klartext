# Name clearance before the public release

Status: preliminary search completed on 23 September 2026. **Klartext is rejected
for public 1.0; Nivune is the selected replacement after a preliminary exact-name,
market, and namespace screen.**

The working name **Klartext** is not planned for trademark registration. Open-
source publication does not remove the risk of conflicting with earlier naming
or trademark rights. This document records a lightweight risk screen, not a
legal opinion and not proof that any name is legally available in every country.

## Search scope

The search covered `Klartext` and obvious spacing/case variants in
DPMAregister's German, EU, and international holdings, with classes 9 and 42 as
the initial filter. The actual goods and services descriptions were reviewed
rather than treating a class number alone as decisive. EU results were checked
against EUIPO eSearch. Current product usage was checked through search engines,
GitHub, app-store listings, relevant product pages, and claimed domains.

The decisive DPMAregister query was
`(marke="Klartext") and (kl=9 or kl=42)`. It returned 26 results on
22 September 2026. The following entries are the relevant active results, not a
complete reproduction of that result list.

## Replacement-name screen

The first shortlist favored semantic voice and dictation names. That approach was
discarded because the relevant market is crowded and the resulting compounds were
either already used or awkward to say. The final round was generated from random
consonant-vowel syllables without using the owner's name, `voice`, `type`,
`dictation`, or another product term. Candidates were filtered for simple spelling
and pronunciation before any availability search. Directly conflicting candidates
were rejected rather than stretched into a spelling variant.

**Selected name: `Nivune`, pronounced approximately `Ni-wu-ne`.** It is an
invented three-syllable sign with no intended product meaning or reference to the
project owner. The product name is deliberately independent from the personal wake
phrase. The default suggestions are `Diktat starten` and `Start dictation`, and
users may record any valid phrase of two to five words.

| Check | Result on 23 September 2026 | Assessment |
| --- | --- | --- |
| DPMAregister, German/EU/international holdings | No result for `(marke="Nivune") and (kl=9 or kl=42)` | No exact mark identified in the initial software/services classes |
| Current products, stores, repositories, and web search | No current exact-name dictation, transcription, or software product identified. Search results were ordinary-language occurrences in southern African languages and an unrelated Turkish lighting-product name | Passed the same-category exact-name screen; unrelated uses still prevent any claim that the word is globally unique |
| `.com` and `.app` | Official registry RDAP endpoints returned `200` for `nivune.com` and `404` for `nivune.app` | `.com` is registered by a third party; `.app` appeared unregistered. Neither was reserved or purchased for this project |
| GitHub organization and npm package | Official APIs returned `404` for `github.com/nivune` and `npmjs.com/package/nivune` | Unclaimed at the check time; **not reserved or created** |

The repository and current Vercel address still contain `klartext`; those are
external renames, not evidence that the former product name remains approved.
Domain or namespace availability can change at any time. Re-run the checks directly
before registration or public launch, and obtain specialist advice before material
commercial investment or asserting trademark exclusivity.

## Consequence

Do not publish binaries, repositories, a landing page, social accounts, or
release announcements under **Klartext**. Existing local alpha candidates may
remain technical test artifacts, but their name is not release-approved.

The source and package branding now use **Nivune**. Stable lower-case storage
keys, the old model filename, and existing profile directories remain accepted as
explicit compatibility identifiers so 0.3.0 settings and downloaded local models
are not orphaned. The public repository, web address, final signed package, and
release announcements must use Nivune before 1.0. Registering a trademark is
not a condition for this open-source release.
